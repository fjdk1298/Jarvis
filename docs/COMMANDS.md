# Command Examples

These examples reflect the kinds of commands this Jarvis build is designed to handle well.

## Wake and Session Control

- `Hey Jarvis`
- `go to sleep`
- `sleep mode`
- `stand by`
- `stop`
- `wait`

## Websites and Search

- `open YouTube`
- `open YouTube in Chrome`
- `search YouTube for Interstellar soundtrack`
- `open Netflix`
- `open Gmail`
- `search Google for weather in Budapest`
- `search Google for today's tech news`

## PC Actions

- `open Spotify`
- `open Chrome`
- `open Settings`
- `close Chrome`
- `close Spotify`

## Utility Questions

- `what year is it`
- `what time is it`
- `what day is it`
- `what is the weather today`

## Conversational Examples

- `Hey Jarvis, how are you doing`
- `what should I do today`
- `remind me what I just said`

## Tips

- Speak clearly after the wake phrase.
- For the best results, ask one action at a time.
- If a command is vague, follow it immediately with a more specific version.
